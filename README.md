# Technical SEO Schema Lab

A beginner-friendly, static technical SEO project built with HTML, CSS, JavaScript, and JSON-LD.

## Features
- Search snippet preview with live title/description character counts
- JSON-LD JSON-syntax checker
- Technical SEO deployment checklist with progress indicator
- Accessible controls and responsive layout
- Example `WebSite` and `Organization` JSON-LD in the HTML head

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy to GitHub Pages
1. Create a public repository named `technical-seo-schema-lab`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, `robots.txt`, and `sitemap.xml`.
3. Replace every `YOUR-USERNAME` placeholder in `index.html`, `robots.txt`, and `sitemap.xml` with your GitHub username and actual Pages URL.
4. Commit the changes.
5. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish and open the published URL.
7. Run the real live URL through https://validator.schema.org/ and https://search.google.com/test/rich-results.
8. Capture your own screenshots of the actual validator output and your own GitHub commit.

## Important notes
- This is a learning/demo project, not a claim of client work or an audit of another site.
- The JSON-LD checker in this project validates JSON syntax only. It does not validate Schema.org vocabulary or Google rich-result eligibility.
- Google may not show rich results even when structured data is valid.
- Only mark checklist items complete after you actually complete them.
- Use genuine deployment and validation screenshots; do not submit mockups as evidence.
